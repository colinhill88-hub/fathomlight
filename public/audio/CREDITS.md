# Sound file credits

Every recorded sound file in the game is listed here (Colin's decision, Nov 21, 2026). Only **public domain or CC0** files are allowed: no CC-BY, no "royalty-free" licences with their own terms, nothing non-commercial. Files ship inside the build and are never streamed from another site. See `src/audio/samples.ts` for how to add one and `docs/phase-16-audio-audit.md` for the shortlist.
